KeePass Backup

A personal Windows tool that copies a KeePass password database to the owner's own Google Drive on a schedule.

Privacy policy

Your Windows PC KeePass database (.kdbx), already encrypted by KeePass
Your Google Drive A backup folder created by this app

Nothing passes through any other server. The app runs on your computer and talks only to Google.

What it does

A scheduled task on the owner's computer runs every 30 minutes and:

  1. checks whether the KeePass database file has changed since the last backup;
  2. if it has, uploads a copy to a backup folder in Google Drive that the app created itself;
  3. verifies the upload by comparing checksums;
  4. moves old copies to the Google Drive trash according to a retention policy (all copies for 7 days, one per day for 30 days, one per month for 12 months).

Google data it uses

The app requests a single permission: https://www.googleapis.com/auth/drive.file. With it, the app can see and manage only the files and folders it has created. It cannot read any other files in Google Drive and does not access Gmail, Contacts, Calendar or any other Google service.

Details are in the privacy policy.

Who it is for

KeePass Backup is a personal tool used by its developer for their own data. It is not a commercial service, has no user accounts, collects no analytics and runs no servers. The source code is a pair of PowerShell scripts.
