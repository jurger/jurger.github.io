KeePass Backup

Privacy policy

Effective October 1, 2026

KeePass Backup (“the app”) is a personal Windows tool that copies a KeePass password database to the user's own Google Drive. This policy explains what Google user data the app accesses and what it does with it.

Who runs the app

The app runs entirely on the user's own computer as two PowerShell scripts. The developer operates no servers, websites or databases for the app and receives no data from it.

Google user data the app accesses

The app requests one OAuth scope: https://www.googleapis.com/auth/drive.file. This scope limits the app to files and folders it has created itself. Specifically, the app accesses:

  • the backup folder it creates in the user's Google Drive;
  • the backup files it uploads to that folder (copies of the KeePass database);
  • metadata of those files: ID, name, size, creation time, MD5 checksum and whether the file is in the trash.

The app cannot see any other files in Google Drive and does not access the user's name, email address, contacts, Gmail, Calendar or any other Google data.

How the data is used

The data is used only to provide the backup function:

  • to create the backup folder and upload new backup files;
  • to confirm that an upload succeeded by comparing checksums;
  • to check that the latest backup still exists;
  • to move old backups to the Google Drive trash under the retention policy.

The backup files are KeePass databases encrypted by KeePass with the user's master password. The app never decrypts or reads their contents.

Storage and security

  • Backup files are stored only in the user's own Google Drive.
  • The OAuth refresh token is stored on the user's computer, encrypted with Windows Data Protection (DPAPI), so only the same Windows user on the same computer can decrypt it.
  • A local log file records file names, times and error messages. It contains no passwords, tokens or database contents.
  • All communication with Google uses HTTPS.

Sharing

Google user data is not sold, shared with or transferred to anyone. The app contains no analytics, advertising or tracking, and the data is not used to train AI or machine learning models.

KeePass Backup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The user keeps full control of the data:

  • old backups are moved to the Google Drive trash automatically, and Google deletes trashed files after 30 days;
  • the backup folder can be deleted in Google Drive at any time;
  • access can be revoked at myaccount.google.com/permissions;
  • removing the scheduled task and the local app folder deletes the stored token and logs from the computer.

Children

The app is not directed at children under 13 and does not knowingly process their data.
